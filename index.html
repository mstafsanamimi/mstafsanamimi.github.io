About

I hold a Master’s in Statistics from the University of Massachusetts Amherst, where my research focused on Gaussian process regression with fairness constraints. My broader interests span statistical learning, variable selection, censored data, and natural language processing.

Projects

Collaborative research · UMass Amherst

RECAP — Relational Context-Aware Prediction

RECAP uses historical data to discover task-specific features across related database tables. It computes each feature using only data available at the prediction time, then uses a pretrained tabular model to make predictions. We evaluate the approach on RelBench.

Master’s research · UMass Amherst

Gaussian Process Regression with Fairness Constraints

Incorporating fairness constraints into Gaussian process models that handle both qualitative and quantitative variables, reducing bias across protected groups while maintaining predictive accuracy.

Published research · Statistics in Medicine

Variable Selection for Censored Data Using MCAR Scores

A variable-selection procedure for censored high-dimensional data with accelerated failure time models, validated through simulation and real DLBCL microarray data.
